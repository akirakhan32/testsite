# CodifyPros — Design anti-slop (ship gate)

## Do
- Instrument Serif + IBM Plex Sans/Mono
- Ink/paper/copper system; one loud copper object per viewport
- Editorial service rows; asymmetric hero
- Proof only when real (cases, metrics, logos)
- prefers-reduced-motion; motion ≤800ms, purposeful only
- WCAG-friendly contrast on dark UI

## Don't
- Inter / Roboto / Poppins / Space Grotesk as primary
- Neon gradients, mesh blobs, glassmorphism, icon-circle grids
- Stock AI robots / handshakes / glowing brains
- Unlock / cutting-edge / world-class / redefine the future
- Vanity client counts or invented KPIs
- Empty Work / portfolio theater
- Duplicated marketplace testimonials
